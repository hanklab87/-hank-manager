IMPORTANTE
1. Esportare il backup JSON prima dell'aggiornamento e conservarlo fuori dall'app.
2. Copiare i file nella cartella principale del repository GitHub sul PC, mantenendo le relative sottocartelle css e js.
3. Controllare le modifiche in GitHub Desktop, eseguire Commit e Push origin.
4. Verificare le nuove iniziali e il saluto dopo aver modificato il nome.
5. Non importare backup vecchi sull'app senza prima verificare la differenza: potrebbero sovrascrivere modifiche recenti.

Il pacchetto non contiene dati personali, giocatori, partite, configurazioni Supabase o chiavi di accesso.
